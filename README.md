# ClassHub (클래스허브)

학교생활에 필요한 시간표, 일정, 오답 기록, 활동 기록을 한곳에서 관리하는 학생용 통합 관리 앱.

> 종촌고등학교 「생성형 AI를 활용한 나만의 프로그램(앱), 챗봇 제작」 활동(2026.10.26.) 결과물

## 한 줄 소개

시간표, 일정, PDF 오답 정리, 생기부용 활동 기록을 한곳에서 체계적으로 관리하는 학생 맞춤형 통합 관리 앱.

## 사용자 스토리

| 구분 | 스토리 |
| --- | --- |
| **S1** (꼭 필요) | 나는 학생으로서 시간표와 날짜별·시간별 일정을 한곳에서 입력하고 확인하고 싶다. 그래야 여러 앱을 번갈아 보지 않고도 중요한 일정을 놓치지 않을 수 있다. |
| **S2** (꼭 필요) | 나는 학생으로서 PDF 문제지·학습지에서 필요한 부분만 잘라 내고 그 위에 풀이와 메모를 적고 싶다. 그래야 틀린 문제와 오답 원인을 한눈에 정리해 같은 실수를 반복하지 않을 수 있다. |
| **S3** (있으면 좋음) | 나는 학생으로서 지난 학기에 한 수행평가, 자율 활동, 동아리, 봉사 등을 보기 쉽게 정리하고 싶다. 그래야 생기부에 이미 쓴 내용과 중복되지 않게 하고 쓴 내용을 더 심화할 수 있다. |

## 수용 기준

1. **오답노트**(메인 기능): 업로드한 PDF에서 원하는 부분을 사각형으로 드래그해 잘라 내고, 잘라 낸 이미지 위에 글을 적거나 타이핑해 오답노트로 저장한다. 타이핑한 글자는 끌어서 옮기고, 눌러서 고칠 수 있다(비우면 삭제). PDF는 페이지 번호를 입력해 원하는 쪽으로 바로 이동하고, 과목별로 모아 보며, 올린 PDF는 언제든 지울 수 있다(저장한 오답노트는 유지).
2. **시간표 관리**: 자신의 시간표(요일·교시·과목·선생님 이름)를 입력·수정·삭제할 수 있다. 이미 적은 과목은 목록에서 고르거나 새로 추가한다. 과목명이 길면 글씨가 줄어들고, 너무 길면 `…`로 줄인다.
3. **전체 달력**: 2020~2030년까지 **월간 / 주간 / 하루** 보기로 넘겨 볼 수 있고, 날짜·시간대를 눌러 시간별로 일정(준비물 메모 포함)을 입력한다. 일정이 없는 시간대는 얇게 접히고(눌러서 펼침), 일정을 누르면 상세 보기에서 확인·수정·삭제한다. **하루 보기**는 방학 생활계획표처럼 24시간 원 그래프로 일정을 보여 준다.
4. **활동 관리**: 수행평가·자율·동아리·봉사 등의 활동을 학기별·종류별·날짜순으로 정리해 보고, 생기부에 쓴 내용을 함께 기록해 중복을 확인할 수 있다. 날짜가 필요 없으면 "날짜 표기 안 함"을 체크한다.
5. **반응형**: 컴퓨터, 태블릿, 모바일에서 화면 비율이 깨지지 않고 정상 작동한다.
6. **데이터 유지**: 입력한 데이터는 앱을 닫았다 다시 열어도 유지된다.

## 활동 관리 상세

- 활동 종류: 수행평가 / 자율 활동 / 동아리 / 봉사 / 기타
- 기록 항목: 활동명, 종류, 날짜(선택), 학기·학년, 설명, 생기부에 쓴 내용, 메모
- 보기 방식: 학기별 · 종류별 · 날짜순 정렬 및 검색
- 중복 방지: 비슷한 활동명이 이미 있으면 경고 표시
- 상세 설계: `activity_management_spec.md` 참고

## 디자인 방향

- 로고: 책 세 권 쌓인 아이콘(파랑·초록·주황, 파란 책에 빨간 책갈피) + ClassHub 글자
- 분위기: 로고 색(파랑·초록·주황)을 쓴 알록달록하고 아기자기한 느낌, 둥근 모서리
- 아이콘: 이모지 대신 로고와 같은 평면·둥근 스타일의 자체 SVG 아이콘(`js/icons.js`) 사용. 오답노트 아이콘은 O·X 모양
- 로고와 상단 탭(홈 포함)에 마우스를 올리면 살짝 떠오르며 움직이는 애니메이션
- 메인 화면(PC 기준): 대표 기능 카드 4개를 세로로 배치, 가로 길이는 화면 왼쪽부터 약 3/5, 앱 이름(로고)은 오른쪽 위. 오른쪽의 일정 상자는 크기가 고정되어 있고 내용이 많아지면 안에서 스크롤된다.
  - 오답노트: pdf파일을 잘라내고 오답정리를 해요.
  - 시간표: 나의 시간표를 입력하고 관리해요.
  - 달력: 날짜 별로 자신의 학업 일정을 관리해요.
  - 활동 관리: 현재까지의 학업 활동을 관리해요.
- 태블릿·모바일: 카드가 화면 폭에 맞게 재배치

## Firebase 연결 (2026-10-28)

Firebase 프로젝트 `classhub-e35f2`의 Spark 요금제, 웹앱, Google Authentication, 서울 리전 Cloud Firestore를 설정했다. `jaettak.github.io` 도메인도 로그인 허용 목록에 추가했다. `firestore.rules`를 Firebase Console에 게시했다.

웹앱 공개 설정값은 `js/firebase-config.js`에 있다. 이 값은 클라이언트용 공개 설정이며 서비스 계정 개인 키가 아니다. 개인 JSON 백업 파일은 프로젝트 폴더 밖에 보관하고 GitHub 저장소에 올리지 않는다.

배포된 사이트에서 Google로 로그인한다. 기존 브라우저의 기록을 옮기려면 설정 → 계정과 동기화 → **이 브라우저의 기존 기록 가져오기**를 누른다. 기존 로컬 기록은 남고, 클라우드에 같은 ID 또는 설정 키가 있으면 클라우드 쪽을 유지한다. 가져오기 전에 기존 백업도 별도로 보관한다.

로그인 방식은 Google만 사용한다. 모든 기기에서 같은 Google 계정으로 로그인한다.

### 저장 범위와 충돌 처리

- 시간표, 일정, 수업 메모, 활동, 성적, 일반 메모, 설정, 타이머 기록 등 텍스트 데이터는 `users/{uid}/records/{key__id}`에 저장한다. 목록은 항목 ID별 문서로 나뉘어 서로 다른 항목의 수정이 전체 목록을 덮지 않는다.
- 같은 항목을 두 기기에서 동시에 수정하면 마지막으로 서버에 반영된 값이 적용된다. 오프라인 변경은 계정별 로컬 대기열에 보관하고 연결 후 재시도한다. 충돌이 중요한 경우 수정 전 JSON 백업을 보관한다.
- `captures`와 이미지 저장소 `img`는 계정별 브라우저 로컬 전용이다. PDF 원본도 클라우드로 올라가지 않는다. 다른 기기에 오답노트를 옮기려면 설정의 JSON 백업·복원을 사용한다.
- 설정의 JSON 백업은 현재 로그인 계정의 로컬 캐시와 그 기기의 오답 이미지를 포함한다. 클라우드 저장 완료 여부는 설정의 **계정과 동기화**에서 확인한다. 로그아웃하면 화면의 계정 데이터와 타이머가 닫히고, 대기 중인 저장이 없을 때 동기화 텍스트 캐시를 지운다. 오답 캡처·이미지와 미전송 대기열은 데이터 보호를 위해 남는다. 공용 기기에서는 브라우저 사이트 데이터도 삭제한다.
- 자동 보관·삭제는 수행하지 않는다.

### 확인이 필요한 실제 환경 테스트

로컬 HTTP 서버에서 Google 로그인 후 Firestore 연결을 확인했다. 임시 메모를 저장하고 Firebase Console의 `users/{uid}/records` 문서로 저장된 것을 확인했다. 두 번째 탭에도 메모와 삭제가 반영됐다. 배포된 GitHub Pages에서의 로그인, 실제 두 기기 간 동기화, 오프라인 재시도, 기존 데이터 이전, 다른 계정의 접근 차단은 아직 확인해야 한다.

## 과목별 색상 설정 (추가)

- 시간표에서 **과목별 색상** 버튼을 눌러 모든 등록 과목의 색상을 한 번에 변경할 수 있다.
- 각 교시를 누른 뒤 **과목 색상** 선택기로 해당 과목의 색상을 정할 수도 있다.
- 같은 과목은 내 시간표·친구 시간표·홈·일정 관리의 수업 표시·성적 분석에서 동일한 색상을 사용한다.
- **자동 색상** 체크 시 이전 기본 색상으로 돌아간다.
- 색상은 기존 브라우저 데이터의 `subjectColors` 키에 저장되며 백업/복원에 포함된다. 기존 데이터는 유지된다.


## 교시별 시간 및 일정 자동 연동 (추가)
- 시간표 → '교시별 시간 설정'에서 교시마다 시작·종료 시간을 지정한다. 입력하지 않은 교시는 기존처럼 시간표에만 표시된다.
- 시간 입력한 **내 시간표** 수업은 일정 관리의 월간·주간·하루 보기 및 원 그래프에 자동으로 나타난다. 기존 일정을 덮어쓰거나 중복 저장하지 않는다.
- 요일, 과목, 교시 시간 변경은 일정 관리에 자동 반영된다. 친구 시간표는 내 일정에 연동되지 않는다.
- 일정 추가 → 반복에서 '매주 (요일 선택)'을 고르면 요일을 복수 선택할 수 있다. '평일 선택' 및 '전체 선택' 버튼도 제공한다.
- 수업 자동 표시는 현재 시간표의 반복적인 주간 패턴이므로 학교 휴업일/공휴일을 자동 인식하지 않는다.


## 추가 수정 (수업별 메모·반복 일정·색상·홈)
- 시간표에서 자동 생성된 수업마다 날짜별 메모 저장 및 수정 가능. 다른 날짜의 같은 교시는 서로 구분해 저장.
- 주간 보기에서 수업 목록 접기/펼치기 버튼 제공(상태 저장). 시간대의 수업 일정은 그대로 유지.
- 신규 반복 일정 선택의 매달 옵션 제거. 이전에 저장된 매달 반복 일정은 데이터 보호를 위해 계속 표시됨.
- 일정 색상 자유 선택 및 최근 저장 색상 최대 5개 보관.
- 메인 빨간 북마크에는 오늘 날짜의 직접 등록 일정만 시작·종료 시간과 함께 표시(요일 반복도 오늘 해당할 경우에만 표시).
